# Personal Portfolio Website

A responsive personal portfolio website for Mantena Mourya Raghava Varma, built with HTML5, CSS3 and vanilla JavaScript.

## Files
- `index.html` — page structure and all portfolio sections
- `style.css` — visual design, light/dark themes and responsive layouts
- `script.js` — theme toggle, mobile navigation, active section highlighting and contact form validation
- `assets/profile.jpg` — supplied profile avatar

## Run locally
1. Download and extract the project ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build tools or package installation are required.

## Contact form note
The form validates Name, Email and Message in the browser and displays a success message. It does not send or store messages because no backend or email service is connected.
